# Smart Tomato Crop Advisor

A Flask/Jinja web app for small and rural tomato farmers with three modules:

1. **AI Leaf Disease Detection** — CNN classifier (~91.15% validation accuracy on PlantVillage-style data)
2. **Soil Moisture & Irrigation Advisor** — type your area, get a 5-day weather-based dashboard with a Random Forest irrigation recommendation
3. **Weather Alerts** — 5-day forecast with simple rain/heat/frost flags

Plus a floating **Gemini-powered chatbot** (top-right corner, English/Tamil toggle) for open-ended farmer questions.

| `GEMINI_API_KEY`        | Disease advice text + chatbot (Google AI Studio) | Falls back to a short apology message|

```bash

```

```bash

```

## 2. Important honesty notes (please keep these in any demo/presentation)

- **"Estimated Soil Moisture" is not a sensor reading.** It's a simple water-balance heuristic (`modules/soil_moisture_estimator.py`) combining forecast rainfall with a temperature/humidity evapotranspiration proxy. It is clearly labeled as an estimate everywhere in the UI and API.
- **The Random Forest irrigation model is trained on a synthetic, rule-derived dataset** (`data/generate_soil_moisture_dataset.py`), because no real sensor-labeled farm dataset was available. The labeling rule is fully documented in that file. Test accuracy is ~85% on held-out synthetic data — this measures how well the model learned the rule, not real-world irrigation accuracy.
- **Sowing guidance is rule-based, not Random Forest output.** There's no historical "sowing succeeded/failed" dataset to train on, so it's an explicit weather-threshold heuristic, always labeled "weather-based guidance" — never presented as a scientific guarantee.
- **Dashboard advice text (irrigation/weather/maintenance/sowing) is deterministic/rule-based**, not generated by Gemini live — this keeps the core numbers reliable and reproducible even with no internet during a demo. Gemini is used specifically for the **chatbot**, where open-ended Q&A is the right use case for an LLM.
- **The disease CNN can be confidently wrong on real-world photos** because it was trained on PlantVillage-style (clean, lab-like) images. For a live demo, use good lighting and a plain background.

## 3. Project structure

```
app.py                              Flask routes
modules/
  disease_predictor.py              CNN leaf disease inference
  disease_model.h5, class_indices.json
  soil_moisture_estimator.py        Water-balance "Estimated Soil Moisture" heuristic
  soil_moisture_predictor.py        Random Forest wrapper
  soil_moisture_model.pkl, soil_moisture_encoders.pkl   (trained model)
  rule_based_advisor.py             Bilingual dashboard advice text
  weather_api.py                    OpenWeatherMap wrapper (+ mock fallback)
  gemini_advisor.py                 Disease advice text + farmer chatbot (Gemini)
  voice_advisor.py                  Text-to-speech (gTTS)
  translations.py                   All EN/TA UI strings
data/
  generate_soil_moisture_dataset.py Synthetic training data generator (documented rule)
  soil_moisture_dataset.csv
model_training/
  train_soil_moisture_model.py      Random Forest training script
templates/                          Jinja pages + chatbot partial
static/
  css/style.css                     Purple/black futuristic theme + dashboard + chatbot styles
  js/                                disease.js, soil.js, weather.js, lang.js, chatbot.js
```

## 4. What changed in this update

- Soil module now takes only a **location** as the required input (soil type / growth stage are optional, in a collapsible "Advanced options" section with sensible tomato defaults).
- New 5-day dashboard: current conditions tiles, a rainfall (bars) / humidity (line) / estimated soil moisture (dashed line) chart, per-day Random Forest irrigation badges (LOW/MEDIUM/HIGH), and four advice sections (irrigation, weather situation, crop maintenance, sowing guidance).
- Trained an actual Random Forest model + documented synthetic dataset + training pipeline (none existed before).
- Added a floating Gemini chatbot (top-right, EN/TA toggle) on every page for open-ended farmer questions.
- Disease detector and its `/api/detect-disease` route are unchanged.
